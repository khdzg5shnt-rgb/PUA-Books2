# 场景路由

从上往下使用第一个符合事实的条目。优先级只用于解决本轮动作冲突，不是人的等级，也不计算兴趣概率。

| 顺序 | 场景 | 方法 | 动作 |
| --- | --- | --- | --- |
| R00 | 输入核对 | [M01](METHOD_CARDS.md#m01-核对对象与原句) | 仅核对会改变回复的一项缺口 |
| R01 | 拒绝联系 | [M23](METHOD_CARDS.md#m23-尊重拒绝的具体范围) | 停止私人联系；已回应过就不再发结束消息 |
| R02 | 身体界限 | [M23](METHOD_CARDS.md#m23-尊重拒绝的具体范围) | 立即停止该身体方向，不用其他信号抵消 |
| R03 | 拒绝恋爱发展 | [M23](METHOD_CARDS.md#m23-尊重拒绝的具体范围) | 接受当前关系意愿，不再换说法推进 |
| R04 | 本轮已经发过 | [M02](METHOD_CARDS.md#m02-等对方回这一轮) | 最后是用户消息，不补发第二条 |
| R05 | 明确话题或渠道边界 | [M23](METHOD_CARDS.md#m23-尊重拒绝的具体范围) | 停止该话题或换平台请求，不扩大成全部联系意愿 |
| R06 | 明确无礼 | [M22](METHOD_CARDS.md#m22-表达边界) | 仅对已确认的具体无礼设边界 |
| R07 | 具体行为修复 | [M21](METHOD_CARDS.md#m21-有依据的修复) | 先修复已确认的影响 |
| R08 | 替代时间 | [M16](METHOD_CARDS.md#m16-承接替代时间或重约) | 落实替代安排优先于判断文字热度 |
| R09 | 活动意愿与安排 | [M15](METHOD_CARDS.md#m15-确认已答应的安排) | 分清一般意愿与具体约定，补一项关键安排 |
| R10 | 拒约无替代 | [M17](METHOD_CARDS.md#m17-没替代方案时收住) | 本轮收住，不换日期追问 |
| R11 | 只拒绝活动 | [M23](METHOD_CARDS.md#m23-尊重拒绝的具体范围) | 尊重活动偏好；是否见面仍依据其他事实 |
| R12 | 纠正事实 | [M20](METHOD_CARDS.md#m20-接住纠正或澄清) | 接受纠正，不强行曲解 |
| R13 | 完整短答 | [M18](METHOD_CARDS.md#m18-完整短答照常接) | 不把完整短答判成低投入 |
| R14 | 连续低投入 | [M19](METHOD_CARDS.md#m19-持续单边时停止加码) | 当前仍低投入且没有待落实安排时停止救场 |
| R15 | 真实困扰 | [M11](METHOD_CARDS.md#m11-接住困扰) | 先回应事情与已表达的感受 |
| R16 | 明确求建议 | [M13](METHOD_CARDS.md#m13-回答她确实提出的求助) | 明确求办法或有紧要实际事务时先提供可行帮助，不机械套共情四步 |
| R17 | 好消息 | [M12](METHOD_CARDS.md#m12-一起高兴) | 接住她分享的具体乐趣 |
| R18 | 认真问题 | [M04](METHOD_CARDS.md#m04-回应问题并露出一点自己) | 先用真实信息回答 |
| R19 | 见面之后 | [M24](METHOD_CARDS.md#m24-见面后的真实反馈) | 根据真实见面反馈回应 |
| R20 | 明确邀约目标 | [M14](METHOD_CARDS.md#m14-一次具体邀约) | 有事实与双向基础时提出具体邀请 |
| R21 | 邀约缺信息 | [M01](METHOD_CARDS.md#m01-核对对象与原句) | 只核对一项关键时间或活动信息，不能编造 |
| R22 | 共同角色正在继续 | [M07](METHOD_CARDS.md#m07-共同角色玩笑) | 只沿双方正在玩的角色 |
| R23 | 真实共同回扣 | [M05](METHOD_CARDS.md#m05-回扣共同话题) | 优先双方已有共同素材 |
| R24 | 双向接梗 | [M06](METHOD_CARDS.md#m06-轻量夸张或曲解) | 轻量相近强度回应 |
| R25 | 需要开场 | [M25](METHOD_CARDS.md#m25-开场或自然重联) | 从当前具体情境或共同经历开始 |
| R26 | 明确想表达欣赏 | [M09](METHOD_CARDS.md#m09-具体欣赏) | 欣赏具体已知细节，不编内心 |
| R27 | 日常分享 | [M03](METHOD_CARDS.md#m03-接住具体内容) | 承接一项具体信息 |
| R28 | 最简回应 | [M03](METHOD_CARDS.md#m03-接住具体内容) | 证据不足时普通回应，保留未知 |

机器入口：[router.json](router.json)。先读图、再填结构化事实、再路由；不要把“哈哈”“忙”“你好”做成读心关键词。路由输出一个主方法，成稿统一经过M26。M08、M10等方法只在其适用条件成立时辅助主方法，不能每轮叠加。

`advice_requested`表示她明确在求办法，`urgent_practical_need`表示可确认的紧要实际事务。两者可与难过或着急并存；这时走R16而非只做情绪复述。事实字段仍需先核原文。

`invitation=open_to_activity`只表示对共同活动开放，`accepted`表示接受了具体邀请；两者都可进入M15，但成稿必须分别处理，不能补造日期或把意愿升级为实际赴约。

`refusal_scope=channel`只表示拒绝换联系方式或平台，走R05；`contact`表示明确不再私人联系，走R01。先按原话核范围，不能因拒加微信断定拒绝全部交流，也不能据此假定仍愿意聊。
