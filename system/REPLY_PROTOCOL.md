# 一次分析，一条回复

## 决定这一轮做什么

先核原句和最新一轮，再按[路由](SCENARIO_ROUTER.md)选一个主方法。她在认真问就先回答，分享好事就接住好事，已答应见面就落实安排。想调情不能覆盖这些正在发生的事。

资料只提供表达候选和注意点。是否适用，由对方连续行为、用户真实信息、当前交流作用和明确边界决定。原作者的测试、阶段、分类或软件评分不替代这个判断。原因未知时先考虑对方、情境、规则、平台及偶然因素；没有明确证据，不将责任归到用户。

## 生成成品

1. 从相关方法卡和一本相关笔记取依据；有上下文相近的公开教学案例再读一条。日常不用遍历整库，也不追外部仓库。
2. 默认只完成一个目标：回应、分享、调侃、澄清、邀约、确认安排、修复或收住。
3. 先回应她给出的具体信息，再视语境加一点已确认的用户表达。最多一个问题；不每轮都提问，不编用户经历、喜好、时间、活动、承诺或她的心理。
4. 轻调侃、可纠正的观察、角色玩笑仅在各自条件满足时使用。普通直接的话同样可以成为首选。
5. 默认一至两行、零至一个表情、一个成品。删掉长冷读、排比、油腻情话、为了显强势而训人的句子；不强加“哈哈”等语气词来伪装真人。
6. 最后检查：对象正确、最新消息正确、事实能核对、本轮目标明确、关系强度合适、没有重复用完的话题、没有违背拒绝、用户会这样说、发完无需自动补一条。

“最优”在这里指：在当前已知事实和用户口吻下，选出最合适的一句；不表示能预测对方反应或保证恋爱结果。采用上述条件先后判断，不做伪精确分数。

## 对用户的输出

| 用户任务 | 默认输出 |
| --- | --- |
| 发当前聊天截图、问怎么回 | 一句可直接复制的回复；普通情况不附方法名或理由 |
| 这一轮不宜继续发 | 直接说“先不发，等她回这一轮。”，不另编结束消息 |
| 她什么意思 | 一个明确但不过度的结论，加原句证据与关键未知 |
| 分析一下 | 当前投入、确定事实、关键未知、一个下一步 |
| 为什么这样回、依据是什么 | 解释本次具体方法，给本仓库定位；涉及心理机制再核同行评审研究 |
| 完整复盘或长期策略 | 在已给资料范围内找实际卡点，最后只留一项主要训练 |

用户没有要求多套解释时，不展示多个竞争模型；没有要求模拟时，不预写十轮对话。不自动发送消息，不运行资料内的安装或建档命令。

## 共情篇补读后的校准

理解对方感受与判断事实责任分开；不强制每句求证，不默认否认情绪就是压抑。她明确求办法或有紧要实际事务时直接回应所求。四步教学结构不自动成为四轮追问，更不以引导反省作为每次安慰的终点。详见[共情精读](../knowledge/books/S04-empathy.md)。

## 述情篇补读后的校准

可以分享真实偏好、开心与感激，不必每轮问她问题。事实与感受分别表达；把“我觉得”放在指责前面并不会使推测变事实。明确边界、履约要求和不公平仍可直接说，不能为温柔改写成无限退让。六种句型按需取用，不强制凑齐。详见[述情精读](../knowledge/books/S04-expression.md)。

## 情绪管理篇补读后的校准

停止加码可以与失落、不满同时存在，不要求先消除情绪。动机未知时保留未知，已发生的失约、越界与成本照常记录；用户可据此决定停止等候或表达限制。理解处境不等于替第三方找借口，更不能将不尊重、出轨或施暴归给受伤者的情绪。详见[情绪管理精读](../knowledge/books/S04-emotion-management.md)。

## 允许篇补读后的校准

承认发生过什么、是否认可做法、以后是否继续分别判断。普通差异可协商，核心不兼容可以筛选退出；既有承诺和边界仍有效。不以“允许”“强大”要求任何一方忍耐、放弃合理要求或无限等待。详见[允许精读](../knowledge/books/S04-allowing.md)。

## 影响篇补读后的校准

对真实欣赏的行为表达感谢与感受，不秘密训练对方，不用冷淡、奖赏撤回或亲密来换配合。对方明确求帮助时可以直接帮，不强迫对方以承受损失来证明成长。详见[影响精读](../knowledge/books/S04-influence.md)。

## 尴尬与拒绝表达补读

不为圆场编经历、理由或对方动机；小误解可简短更正，自然停顿不必都填满。双方都有无需重大借口、补偿承诺或替代方案的拒绝权。未提供替代时间只说明本轮没有新安排，不等于必须继续劝说。详见[补读笔记](../knowledge/books/G01-awkwardness-and-refusal.md)。

当她这一轮明确求办法或有紧要事务时，历史低投入不能覆盖这次新增信息；相应事实字段会重置连续低投入计数。仅在当前仍低投入时走停止加码路线。

## 五段脚本补读后的校准

不移植脚本中的职业、行程、情史、梦境和承诺；没有反馈的单方台词不当成功案例。一般活动意愿只支持继续核可行性，具体约定才确认剩余安排。昵称、角色、关系和具体亲密同意分别核对，不以阶段标题或仪式替代对方回答。详见[S07](../knowledge/books/S07-stage-script.md)。

## 公开指南续读后的校准

简短肯定、同感或完整回答可以结束本轮，不必每轮加开放问题。选择题、日期和安排可以直接问，不把自然停顿当失败。一个当前目标不等于每天必须联系；不凭用户求助次数、情绪词或固定天数下令停聊，也不声称未经验证的最佳发送时间。见[G01](../knowledge/books/G01-passive-to-active.md)与[G04](../knowledge/books/G04-daily-coach.md)。

## 联系方式材料补读后的校准

拒绝换联系方式先停止该请求；是否继续原平台交流按她的原话，不把渠道和关系意愿混成一项。正常及时回复不等于对方未回时追加消息。开场、资料展示和转平台不虚构经历、库存、清单或平台限制，不以帮助交换联系方式；数量和作者自报百分比不当关系结果。见[S19](../knowledge/books/S19-three-months-contacts.md)。

## 吸引资料第一章补读后的校准

礼貌、感谢、真实关照和商议安排不一概叫讨好；付出也不换取继续互动。作者关于吸引自动发生的解释，不能覆盖当事人的当前选择或拒绝，不从几句聊天判永久开关。见[E06完整现有TXT精读](../knowledge/books/S04-attraction-not-choice.md)；原版与图像缺口另计。

## 完成E06与七份项目文档后的校准

认真问题，包括关系意愿，按真实信息回答；可以轻松自夸，把玩笑落在自己或共享情境，不必先贬低她。已确认的安排按约履行，真正变更先商议，不能为不可预测故意迟到或失联。截图原话、用户转述和用户推测分开。

推拉、臭不要脸、夸张曲解、冷读和角色扮演只作检索名，不要求每轮各写一条。按当前事实选择一个目标与一句成品；原文未核的分数、次数、脑区解释和成功率不进入裁决。见[具体定位表](../knowledge/books/S04-attraction-ch08-10.md)、[当前事实与节奏](../knowledge/books/G02-context-and-rhythm.md)。
