# 拒绝范围与当前回复

依据用户明确的指导原则，以及已读[B011边界段落](../books/B011-defense-empathy.md#用于当前边界)、[B012信号取舍](../books/B012-ch05.md#信号不能覆盖选择)整理。这里是编辑与工作流程规则，没有新增恋爱效果实验，也不靠关键词判断真实意愿。

## 按拒绝范围处理当前一轮

| 已核的拒绝 | 始终保留的限制 | 当前可以做什么 |
| --- | --- | --- |
| 全部私人联系 | 停止联系，不换平台，不另发告别或解释 | 告诉用户先不发；不能因对方表情或普通内容自动重启联系 |
| 身体或性方向 | 立即停止该方向，不用其他信号抵消 | 如需回应可简短承接；她新问普通问题时正常回答，不恢复该方向 |
| 恋爱发展 | 不继续劝说或追求，礼貌不算改变态度 | 用户真实愿意普通交流时，可回应具体新内容；也可以退出 |
| 某项活动 | 不追同一活动、不换日期逼问 | 可接新的普通内容，不能把拒绝扩大成全部联系 |
| 某个渠道、话题或称呼 | 不再索取或重复所拒内容 | 按原话在允许范围回应，不借玩笑试探 |

本人明确改变哪一项意愿，才重核哪一项。正常新消息不自动解除已有边界。已经承接且对方未回时不再补第二条；需要简短承接也不追加问题。

受压后照做、没有反抗或过去付出，不能单独证明当前自愿；也不据此断言其全部动机。按已知选择条件与本人当前表达判断，条件不清先停下或确认。

## 边界与新内容同时存在

一句话可以同时表达边界并提出正常问题。先保留具体限制，再按当前需要回答的问题、实际求助、纠正或新分享选一个主方法；不强迫整场聊天停止，也不借回答偷偷回到被拒绝的方向。

拒绝的理由本身不算另一项新分享。实际读到拒绝之外的新内容才能标作新分享；若只是不想参加某活动，仍按该活动的拒绝处理。害怕、愤怒或直接说不，也不能自动标作无礼来反击。

## 已经发出与必要新事务

最后是用户已发且未获回复，默认先不发。只有已核实、独立且必要的新事务才单独通知；旧约会被拒绝、原话题没回、想试探兴趣，都不能充作必要事务。通知不表示对方接受新活动，也不解除已有边界。

这些区分由当前助手看原图、时间线和上下文完成。代码只保持已填事实与输出约定的一致性，不识图、不判断动机、不生成或发送消息。

取舍例见[B017文件页176–201](../books/B017-p176-201.md)：对来源中由受迫配合倒推自愿的论证保留证据缺口，不转成归责、施压或推进理由。此为项目判断规则，没有新增恋爱效果或同意机制研究。
