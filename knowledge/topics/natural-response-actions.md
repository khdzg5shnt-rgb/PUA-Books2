# 日常回复动作：把已知信息写成当前一句

这是编辑示范，不是经过实验验证的恋爱话术。以下全为独立虚构情境，不取自真实私人聊天。运行时只选择与截图相符的一行，代入已核实信息，输出一个首选回复；不把整张表或多个候选交给问“怎么回”的用户。

| 已确认的本轮信息 | 主方法与动作 | 仅供理解的虚构示例 |
| --- | --- | --- |
| 她分享自己期待的好消息 | M12：接她高兴的具体细节 | 她：“盯了好久的展终于抢到票了。” 回复：“终于抢到了，这下能去看你惦记的那个展了。” |
| 她认真问已知事实 | M04：直接答，再露出一点真实态度 | 已知本人近期确实在画楼下那只猫。她：“你平时画什么？” 回复：“主要画身边的小东西，最近在画楼下那只猫。” |
| 她真诚赞美一个具体行为 | M09：接下并感谢，无需争输赢 | 她：“你刚才帮忙讲得挺清楚的。” 回复：“这夸奖我收下了，谢谢。” |
| 她提起双方真的做过的事 | M05：回扣同一件共同经历 | 已知两人上次一起走错路。她：“我今天又走错出口了。” 回复：“看来上次那条绕路路线又有传人了。” |
| 她给出具体生活信息 | M03：承接一个点，不强制追问 | 她：“周末把阳台收拾出来了。” 回复：“阳台重新营业了。” |
| 她认真询问已知到达时间 | M04/M26：直接给当前需要的答案 | 已核用户计划七点到。她：“你几点到？” 回复：“我七点到。” |
| 她明确接受了具体活动 | M15：确认尚缺的安排 | 已知周六、看展均已答应，只有时间未定。回复：“那周六两点在展馆门口见，可以吗？” |

示例里的个人经历只能在事实已给出时使用；未确认就删去，不能把表内猫、展览、阳台或共同经历套成用户事实。她已说清时间时也不再问一次。可轻松但不必每句造梗，简单接住信息已经能完成这一轮。

对应来源：[B004第八章](../books/B004-ch08.md)的倾听、感谢与不抢话；[第十章](../books/B004-ch10.md)的真实经历、回扣与安排；[原有方法卡](../../system/METHOD_CARDS.md)共同约束。书中作者主张与本系统编辑决定不等于微信效果的研究证据；研究范围另见[证据记录](evidence.md)。

[S23二次摘要](../books/S23-chen-summary-handbook.md)进一步提醒：本轮目标可以只是回答、分享或确认；不要为了展示技巧给每个简单问题附加暧昧和追问。该来源及这些虚构示例均不证明恋爱效果。

## 先核原话，再承接具体感受

[B010第七分册](../books/B010-difficult-people.md#接回当前一轮)补充：回应对方已经透露的具体困难和感受，不用固定“我懂你”替代，也不把失望擅自加重成愤怒或创伤。她明确求办法时就回应所求，不强制复述或每句求证；不想谈则收住。

这不是禁止普通“我理解”，也不意味着承接一句就必然化解冲突。真实分享不编共同经历，表达界限不要求诊断人格，感受与事件责任分别核实。怎么回仍只给当前一个成品。

## 理解困扰不需要放大情绪

[B011承接段落](../books/B011-defense-empathy.md#用于承接困扰)补充：接她已经说出的具体事情，不刻意比她更焦虑或更生气，也不靠积极口号跳过她的实际问题。她求办法时回应办法；没有同样经历不编经历。此处为编辑准则，未认证情绪强度决定互动领导的书内说法。
