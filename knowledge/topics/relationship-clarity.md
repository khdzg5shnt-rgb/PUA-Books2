# T12｜确认关系与投入边界

本页整合[B008第十至十三章取舍](../books/B008-ch07-13.md)、[第十八、十九章取舍](../books/B008-ch14-19-tail.md)与既有项目约定；是使用流程，不是经验证的吸引定律。

## 先核关系事实

愿意聊天、主动邀约、实际赴约、身体亲近、明确同意恋爱、明确同意排他，各是不同事实。没有确认关系，不提前要求女朋友义务；已有明确承诺，也不能单方改写成默认开放。没发朋友圈、照片、表情或一次拒约不能独立证明关系状态或欺骗。

## 当前怎么处理

| 已核情境 | 本轮动作 | 不补造的部分 |
| --- | --- | --- |
| 她认真询问关系，用户真实意愿已知 | 用M04直接回答真实意愿，不拿玩笑躲过去 | 不编用户已准备承诺 |
| 用户想确定关系，双方已有持续了解 | 说清自己的希望，核对她是否也愿意 | 不把几次约会当默认答应 |
| 单边投入且没有待落实安排 | 用M19收住，按实际后续重新判断 | 不假装冷漠制造追逐 |
| 花费、空闲或分工超出真实承受 | 用M22说明具体限制或可行安排 | 不靠借款、虚构身份或牺牲全部生活换承诺 |
| 有证据确认具体失约或伤害 | 用M21修复具体影响并兑现 | 不包揽所有原因，不用付出抵消责任 |
| 对方明确不愿发展或停止联系 | 按M23停止相应方向 | 不用见面、身体接触或付出覆盖拒绝 |

只有缺失信息确实会改变回复时才补问一项。日常“怎么回”仍只给一个成品，不把全表发给用户或每轮要求确定关系。

## 表达自己与控制别人分开

用户可以用M10表达一项真实感受、压力、需要或限制，不必演成永远没有困难的人；同时不要求对方立即负责全部情绪。正常关心不自动是讨好，正常自我表达不自动是失去吸引。

自己的界限管理自己的参与方式；不是决定对方必须服从、停止社交或接受亲密。生理反应、关系身份和知情自愿分开，不用任何价值评分、周期推测或投入金额替代。

对方实际持续不尊重，可以依据行为停止参与，不必证明她的真实恶意。若原因仍未知，不默认归到用户外貌、身高、性格或所谓价值低；只讨论证据支持、可以修改的具体部分。
