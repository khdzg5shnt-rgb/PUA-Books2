# 请求、约定与自己的边界

用于M22。先处理当前一件具体事情，保留双方自主与真实安排；普通“怎么回”仍只给一个自然成品。

## 一项请求与边界分开

先核具体要求、对方行为、当时处境、已答应的安排和信息缺口，不从一句话判控制，不自动归责用户。普通请求或意见可以同意、不同意或说明真实限制；已确认的越界不必先证明恶意。

把诚实、尊重拒绝、双方自愿和履行已答应安排，与羞辱、持续逼迫、危险证明或无条件付出分开。设边界管理自己的参与，不接管对方选择，也不取消真实责任；没有过错证据时不默认双方都有错。

只说不接受的具体行为或自己能做什么，必要时退出；不编借口、许补偿或以互骂证明强大。理解处境不等于必须答应，拒绝某要求也不自动证明对方恶意。具体拒绝与是否继续普通交流分别判断。

## 用事实判断具体情况

| 目前能确认什么 | 当前处理 |
| --- | --- |
| 一个正常请求或意见，未见逼迫 | 如实回应是否愿意与能否做到，必要时协商，不急于定性。 |
| 一项真实承诺需要调整 | 说清实际变化与可承担部分；不能用自主之名假装承诺不存在。 |
| 已核实的羞辱、持续逼迫或越界 | 可简短说清限制，必要时结束；不强求用户先体谅或自证。 |
| 拒绝之后又有普通新问题 | 保留拒绝的方向，按当前问题回应；不自动扩大为全部停聊。 |
