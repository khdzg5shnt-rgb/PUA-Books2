## 原主张和可采用的部分

开头以行为、语言、思维、心态、信念、身份六部分解释社交，之后谈回应速度、个人标准、面对否定和群体接话；后半以水结晶、外星人、量子借喻推到所谓信念赋格。文本没有对应的可复核实验和直接证据，这些不是本库解释真人感情的依据。

可以保留两项普通表达动作：有自己的实际偏好与限制；接住正在聊的话题，用一项真实经历参与。两项都不要求先获得完美心态，也不要求控制所有人的意见。

| 原文推断 | 本库处理 |
| --- | --- |
| 迅速回应或收到夸奖开心就是低价值 | 正常回应、开心与礼貌不作为地位或心理诊断；不故意迟回 |
| 只要自己舒服就是正确，有证据也不改变标准 | 个人偏好可以不同；事实错误、失约及明确边界需要按证据修正 |
| 感受到对方抵触必然因为自己先抵触 | 不把被不尊重或受伤自动归责用户；情境、他人行为与未知分别看 |
| 消除自己的情绪就能消除对方行为 | 保留自己的感受与限制，不承诺改变心态能控制他人 |
| 为了获得关注接话并展开故事 | 真实、相关时可分享，不强抢话题；认真问题不能改成展示自己的舞台 |
| 相信对方具备某性格就会变成那样 | 依据连续行为了解人；可纠正观察不能升级为塑造人格、催眠或服从训练 |

购物、群体谈话等多为作者转述或拟例，没有完整结果；量子、水结晶、脑内程序等说法没有在本轮核验，不能包装成心理学或物理学结论。作品标题里的最有效也不是效果证明。
