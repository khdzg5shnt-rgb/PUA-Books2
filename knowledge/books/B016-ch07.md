# B016第七章｜真实边界与亲密欠账分开

已读spine 9《第七章 谈判》全文，当前提取范围`[79044,90701)`，11657字符，含单元标记。[本书身份](B016.md)与[台账](../provenance/B016_ch05_07_reading_2026-11-11.json)固定已读版本。原章的人质谈判类比、作者故事和效果主张分开记录，不把危机场景的控制目标移入亲密关系。

## 原章结构

内容包括谈判专家心态、I.O.U.（你欠我）、额外付出与样板、日常应用、礼物、可协商与不可协商要求、创意要求、事先铺垫、拒绝不愿做的事，以及转述《Getting Past No》的五步模型；最后一组在本章合并第四、五步。该转述不计《Getting Past No》或《Crisis Negotiations》原书通读，也不计原研究已核。

原文把女性比作劫匪，把她说的任何内容理解为战术要求；这种前提不采用。对方不愿继续可以就是拒绝，不能改称不存在拒绝、她不值得或她有问题。用户也可因不兼容或不愿继续退出，不需要贬低任何一方来合理化。

## I.O.U.不进入日常方法

| 来源操作 | 本库处理 |
| --- | --- |
| 把开暖气、让座、接送或改变安排记成欠账 | 真实付出可以被看见，也可拒绝超出意愿的投入；不虚报成本，不把正常关照制造成债务。 |
| 通过礼物、座位或时间换取接吻与亲密 | 不采用。谢谢、接受礼物或接受帮助不形成身体或关系义务；犹豫与拒绝不进入讨价还价。 |
| 已决定答应，却先拖延以显得稀缺 | 不采用固定拖延或假忙。根据真实生活、预算和意愿作答，安排变化如实说。 |
| 赠礼作为对表现的奖励 | 可按真实预算和心意送礼；不把关系变成训练配合，也不把礼物当未来回报的凭据。 |
| 把所有分享解释成索取 | 对方说想去一家店不自动等于让用户买单或立即安排；先看实际表达，有必要再确认。 |

本库保留用户正常边界：可以说今晚不方便、这次不想参加多人活动、预算更适合另一家店；不必假装愿意、夸大牺牲或为拒绝作长篇自证。双方各自决定是否接受安排，用户不能单方面规定对方必须尊重某份相处时间表。

## 清楚的邀请也必须容许拒绝

清楚说明真实的活动、时间与联系方式用途，可以减少信息缺口；不能把未答应说成已约好，不以开始输入姓名制造交出号码的既成事实。

不愿换联系方式、不想约会或不愿亲密时，停止对应方向。原文的消除疑虑、事先铺垫与让人难以说不不用于绕过边界。一起回家、看藏品、感觉熟悉或收过礼物，都不替代当事人对下一项行为的当前意愿。

## 倾听与停止争论

原文转述的暂停、观察、倾听可作为本项目表达选择：先核她确实说了什么和环境限制，不先找用户做错了什么。遇到骚扰、伤害等真实困难，不为改变游戏或恢复浪漫气氛提前结束她的表达，也不借机证明自己更好。她愿意换话题时再跟随，明确求办法则回应实际需要。

临时由双人活动改成多人活动，可以说清自己真实意愿，再由双方决定后续；原文断言任何顺从或拒绝都会失败，没有足够证据，不作结果预测。普通照顾、协商、说不与控制他人分别处理，不按是否始终主导来评价用户。
