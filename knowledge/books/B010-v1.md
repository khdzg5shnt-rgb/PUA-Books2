来源：[B010入口](B010.md)。本节实际顺读原PDF物理页13–90；卷前1–12页另读。页码均为文件物理页。此为原创批判笔记，不是方法有效性认证。

## 章节定位与结论

| 位置 | 作者内容 | 整理后的判断 |
| --- | --- | --- |
| 14–24，引言、第1章 | 心理学史、“黑暗心理学”、黑暗三联征 | 只登记其论述范围。99.99%与0.01%的动机比例没有可核引用；形容一个行为与诊断一个人必须分开。“懂人性便能控制别人”不成立为本库已验证结论。 |
| 25–27，第2章 | 销售、模仿、恐惧、疲劳、混淆和人情债 | 利用疲惫、制造威胁、隐藏目的、用帮忙换服从均不进入聊天方法。活动选择必须允许不参加；不能用二选一偷换尚未同意见面这个前提。 |
| 28–30，第3章 | 面部、嘴唇、手势、双臂、双腿和姿态 | 这些动作最多提出需要结合情境核实的问题，不能独立证明喜欢、抗拒、撒谎、性格或同意。60%–65%的统一沟通占比没有在本章给出可追溯研究。 |
| 31–38，第4章 | 情绪觉察、调节、共情、动机及高低情商分类 | 留下“注意感受并选择表达方式”的提醒；不采用“越没情绪越高情商”、敏感等于暴力、无过错也应道歉、必须原谅等判断。真实表达可以有界限，不要求一次倾倒所有私事。 |
| 39–45，第5章 | 情商与工作、韧性、动机、决策、成功、幸福和目标 | 大量“研究表明”缺作者、年份和可定位文献。相关、预测与因果混用，不能据此承诺恋爱成功，也不能由一次争论反推低情商。 |
| 46–55，第6–7章 | “思想控制”、宣传、重复、紧迫、互惠与社会制度 | 正常影响、公开协商与欺骗胁迫被混在一起。不给别人思考机会、用旧付出逼回报、限制质疑不采用。食品、药物、电磁等阴谋叙述未核实，也与微信指导无直接证明关系。 |
| 56–64，第8章 | NLP历史、四个支柱、模仿与肢体阅读 | 清楚表达、注意环境可以作为普通沟通要求，不证明整个NLP体系有效。“使用多年所以有效”“内心能找到疾病疗法”不作为证据或治疗建议。 |
| 65–71，第9章 | 操纵与说服、人格、思想与行动 | 文中把psychosis与psychopathy混写，并把特质、疾病、犯罪与撒谎直接连起来。相关临床概念须另核，不能据此给聊天对象贴标签。它按“改变想法/改变行动”划分说服与操纵的定义也不作为伦理判断标准。 |
| 72–81，第10章 | 欺骗、侵入空间、羞辱、恐吓以及“恐惧—缓解” | 留下对具体不尊重行为的识别；不接受“操纵者永不道歉”等绝对画像。不把正常幽默、沉默、表扬或拒绝单独算作操纵。不传授制造恐惧再解除的做法。 |
| 82–85，第11–12章 | 催眠、条件反应、洗脑、隔离、剥夺与轰炸式示好 | 不能把专注、讲故事、身体反应等同失去自主决定。节奏导致25倍易受暗示、固定神经通路等说法未核实；不将其变成绕过同意的技巧。 |
| 86–90，第13章与结尾 | 拒绝、边界、避免自责、问责、后果与求助 | 可以明确自身决定、减少参与、保留外部支持。不能承诺“质问一下对方便退缩”，也不建议为证明强势而独自对质。该章匿名研究的结果与前文表述有矛盾，保留缺口而不猜原意。 |

## 接回日常指导

遇到含糊信号，先说明看见的动作或原话，再确定是否确有需要核实的事实；不能由一个动作直接跳到心理结论。对方明确说不时，肢体解读不得推翻这句话。

如果有人把帮忙、花费或过去亲密当成应当回报的理由，先把具体义务与自愿选择分开。礼物和情绪支持不自动产生见面、恋爱或性方面的义务。这是本库的自愿与边界要求，不是声称从本书证实的新心理规律。

情绪调节用于决定怎么表达、是否暂缓发送；不要求吞下委屈、承担未经确认的过错或保持表面平静。明确侮辱可以设边界；一个普通玩笑是否越界仍需上下文。
