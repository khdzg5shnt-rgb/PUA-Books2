# B010第五分册：争议事实、边界与不当标签

来源：[B010入口](B010.md)。实际顺读PDF物理页375–470，卷内署名Jack Mind。以下记录作者内容与本库取舍，不是临床诊断手册，也不收录卷内私人叙述的原话或身份。

## 章节定位与结论

| 位置 | 内容 | 本库取舍 |
| --- | --- | --- |
| 375–381，引言、第1章 | 否定感受、侵犯边界、愤怒压制、转移问题 | 第379页对“限制自己的参与”和“控制别人的生活”的区分可接回边界卡。一个人有不舒服的感受不需别人批准，但感受与争议事实仍分开核实。不能直接认定对方有意或无意。 |
| 382–391，第2章 | 词源、历史、成因、调查、家庭与职场叙述 | 第383页提醒区分一般烦人行为与gaslighting，应保留。电影、历史、匿名病例、HR民调和人口比例未追溯原始材料；不能据此推算聊天对象是施害者的概率。 |

| 394–402，第4章 | 认知失调、短期与长期影响 | 不舒服、矛盾或犹豫可以来自多种情况，不是受到操纵的充分证据。长期预后、抑郁等健康主张未逐项核实，不承诺必然终身伤害或离开即恢复。 |
| 403–408，第5章 | 自恋、控制与否定现实 | 第405页从两句常见否认直接判“自恋者”的做法排除。自恋特质、NPD诊断与一个具体施害行为不能相互替代；事实成立时也不必先诊断才能设边界。 |
| 409–418，第6–7章 | 影响、自我怀疑、道歉、退缩与阶段 | 清单只能提醒关注处境，不是诊断测试。不能从哭泣、安静、低自信、道歉或想被认可直接认定被操纵，也不把普通波动归为固定受害阶段。 |
| 419–420，第8章 | 三十句常见话语 | 不做“听到一句便判坏人”的黑名单。需要看谈论的具体事实、语气、重复模式、实际约定和是否修复；同一句澄清或劝冷静可能出现在不同情境。 |
| 421–428，第9章 | 保持距离、避免刺激、附和、拒绝、弱点和交换 | 包含离开、附和、讨好和不给拒绝等不同方向，不能一并自动执行。不得建议假装行程、通过羞耻操纵对方或长期压抑正常需求。保护自己与争取对方认错是两件事。 |
| 429–438，第10章 | 关注模式、支持、改变与问责 | 第429页明确说争执不等于人人自恋；第431页又说人可改变，与其他章节“永不改变”不一致。疾病成因和治疗效果未认证。可以不接受伤害，不把“拯救他”当作用户义务；也不靠是否对所有人同样无礼来判其有没有疾病。 |
| 439–444，第11章 | “共情者”和“自恋者”的配对 | 情绪振动、自动吸收能量、十倍痛苦、注定结局等缺乏本轮可核依据；不建立这种人物分类和择偶匹配表。共情不等于读心或承担别人的全部情绪。 |
| 445–449，第12章 | 写清争议、求助、边界、对质和离开 | 整理具体事实与保持支持可以作为处境核查；不默认独自对质，也不承诺说一句强硬话就结束控制。书中录像与监控建议没有法律和情境核验，不采用为操作指导，更不上传私人资料到公开库。 |
| 450–458，第13章 | NPD比例、脑结构、成因、治疗与标准 | 作者没有给出完整临床依据；本轮不把比例、脑结构和治疗方案用于聊天指导。清单、雄心、注重外貌或追求肯定都不能单独诊断NPD。 |
| 459–470，第14章与结尾 | 恢复、原谅、兴趣、锻炼、关系去留 | 第459–460页要求受害者为参与动态承担责任的写法，与本库按事实确认责任的原则冲突。不能把遭遇伤害归结为不够爱自己、选错人或不够强；也不要求强制原谅。自我照顾与实际问题处理并行，不保证固定方式最快或最有效。 |

## 接回日常系统

争议先落到一项可核事实。哪句话、哪项约定、哪个行为被否认，是否有原始记录，是否存在合理记忆差异或信息缺口。确认不尊重或反复违约后，可以明确要求或停止参与，无需先证明对方属于某类人格。

“感觉受伤”可以直接承接；“对方故意破坏你的现实感”需要另外的证据。不会用一句否认、一项普通更正或一次不及时回复来判gaslighting，也不因为尚不能诊断就要求继续忍受侮辱。

责任归到已经确认的行为。用户可以改有明确证据的表达方式；不替施害者寻找免除责任的童年理由，不要求用户道歉、退让或治好对方。涉及具体威胁时先处理安全与支持，不将冲突升级成输赢较量。

## 阅读限制

本分册的电影、调查、诊断、治疗与人格机制没有全部回查。正文大量绝对画像相互矛盾，已按位置记录；读完不代表认可。没有收录真实私人聊天、录像、身份、诊断或对象状态。
