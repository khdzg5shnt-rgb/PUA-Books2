# B010第二分册：直觉、归因与持续越界

来源：[B010入口](B010.md)。实际顺读PDF物理页91–152，署名Joseph Griffith。此为当前文件的原创批判笔记；标题相近不代表与第一分册同文，也不作为新的成功案例计数。

## 章节定位与结论

| 位置 | 作者内容 | 整理后的判断 |
| --- | --- | --- |
| 91–104，说明、引言、第1章 | 黑暗面、阴影自我、投射和自我探索 | 作者的隐喻与临床事实分开。被无礼对待而生气，不能证明自己压抑了同样的无礼。把遭遇解释为“吸引来了同类”也不进入归因规则。99.9%与0.1%的比例未提供可靠依据，并与第一分册不同。 |
| 105–108，第2章 | 黑暗三联征、光明三联征与遗传 | 不把人格研究摘要当作个体诊断；缺少自觉、送礼、事业表现或自报家族信息都不足以确定人格障碍。不能以“所有人都有黑暗面”抹平施害责任。 |
| 109–117，第3章 | 偷换原话、移动标准、话题转移、辱骂、散布消息与三角关系 | 保留对可确认行为的核查。一次否认、换话题或玩笑不能直接诊断gaslighting；需要核对原话、争议事实和是否持续发生。不会用反向造谣、第三者刺激或疲劳顺从来回敬。 |
| 118–125，第4章 | 无意识、边缘系统、“解冻—重编程—冻结” | 大脑结构和心理隐喻被直接用来推出读心与控制，证据链不足。对遭遇控制者的处境不能简化成自愿或软弱；也不能反过来由一个亲密行为宣称其已被控制。 |
| 126–133，第5章 | 专注、催眠、打断习惯、混乱与暗示 | 讲故事、意外插话、专注和催眠不是可互换概念；没有证据支持把普通聊天当作可植入任意行为的程序。不能利用困惑、恐惧或触碰使别人失去选择。 |
| 134–140，第6章 | 说服、潜意识广告、渐进请求、大请求后退让、引导问题 | 从小请求逐步推进也必须每一步自愿；不能把一次同意解释为下一步义务。作者称“为你好”不免除诚实与尊重边界。问题中的预设需要单独核实。 |
| 141–150，第7章 | 基线、变化、动作簇、分析情境、直觉及防护 | 可以观察同一个人在具体情境中的实际变化；动作簇仍不等于测谎或读心。感觉不舒服足以暂缓自己参与，但不能据此定别人有罪。书中“不要接受第二意见”与紧接着“找可信者意见”相冲突，不靠猜测消除。 |
| 151–152，第8章 | 回顾阴影自我与操纵 | 主要重述前文，不算新理论或新样本。自我觉察仅针对有证据、可修改的行为，不扩大为人有问题。 |

## 接回日常指导

当一句话让人不舒服时，把“我现在的感觉”“对方实际说做了什么”“我是否继续参与”分开。用户可以停止一场令自己不舒服的互动，不需要先证明对方患有人格障碍；反过来，不舒服本身也不证明对方在算计。

有争议时回到一个具体问题：原话是什么、约定是什么、现在发生了什么变化。按事实判断责任；不接受“你会介意说明你自己也有这个阴影”的自动归责。多个信号只能增加待核问题，不能累加成确定的心理诊断。

安全与自主优先于当场赢过对方。既不把正当道歉说成软弱，也不让用户为未经确认的过错道歉。暂停发送、保持外部支持与减少接触属于参与决定，不包装成保证别人服从的手段。
